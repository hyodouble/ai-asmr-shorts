# ai-asmr-shorts

Claude 스킬로 AI ASMR 수면용 영상을 기획→프롬프트→렌더 검수→후처리→1시간 조립까지 자동화.
쇼핑/쿠팡 연동 없음, 상품 구매 없음, 얼굴/목소리 노출 없음.

주 배포물은 **수면용 1시간 롱폼**이다. 10초 클립 20개를 이어붙여 마스터를 만들고, 순서를 섞은 두 마스터를 번갈아 붙여 1시간까지 반복한다. 숏폼은 같은 클립을 재활용해서 나중에 낸다.

## 니치 (2026-09-01 확정)

**스퀴시 ASMR** — 두 갈래를 한 채널에서 섞는다.

1. **타바 스퀴시(taba squishy)** — 투명 필름에 말랑한 반죽을 봉하고 공기 방울을 주입한 장난감. 누르면 방울이 밀려 다니며 뽀글거린다. TikTok `#tabasquishy` 트렌드, YouTube에 1시간 수면 버전 존재
2. **왁뿌볼** — 말랑이 겉에 얇은 왁스 껍질을 굳힌 국내 유행 완구. 누르면 껍질이 잘게 깨지며 와그작거린다

공통점이 채널 정체성이다: **잔 소리가 촘촘히 이어진다.** 큰 소리 하나로 터뜨리는 연출은 쓰지 않는다.

이전 니치(물리법칙 파괴형 유리 커팅)는 폐기했다. 고정해야 할 축이 계속 늘어나 통제가 안 됐다.

## 진행 상황 (2026-09-01)

- 워크플로우: `SKILL.md` 전면 재작성. 프롬프트 블록 고정/변주 구조, 톤 제거, 노이즈 제거, 조립까지
- 도구: `detone.py`(모델이 넣는 벨/차임 제거), `tonecheck.py`(FFT 톤 검사)
- 영상 생성: **Google Flow / Omni 1.1 Flash**, 720p·10초·x1 = 15크레딧
- 테스트 클립 5편 제작, 마지막 타바 스퀴시 클립으로 소리·화면 승인
- 다음: 승인된 20클립 변주표대로 3클립 선행 생성 → 통과 시 17개 양산 → 1시간 조립

## 이 프로젝트에서 실측으로 알아낸 것

- **모델은 프롬프트 금지어를 무시하고 벨/차임 효과음을 넣는다.** `no chimes, no bells` 를 넣어도 3회 연속 들어갔다. 프롬프트로 재시도하지 말고 `detone.py`로 지운다
- **소음은 증폭 전에 자른다.** 원본이 -37~-48 LUFS라 20 dB 넘게 올려야 하는데, 신호는 1~10 kHz에만 있고 20~200 Hz는 럼블, 10 kHz 위는 히스다. 대역 필터 + `afftdn`으로 SNR 29 → 39 dB
- **`alimiter`는 기본값이 `level=true`라 리밋 후 출력을 도로 올린다.** `limit=0.5`를 걸고도 피크가 +0.6 dBFS로 클리핑났다. `level=disabled` 필수
- **라우드니스 목표는 -20~-24 LUFS.** 원본이 작아 -16까지 밀면 리미터가 계속 물려 뭉갠다

## 사용법

1. 클로드에서 `/ai-asmr-shorts` 실행
2. 씬 목록과 프롬프트를 **승인받은 뒤** Flow에 입력 (크레딧이 곧 돈이다)
3. 생성된 클립을 후처리(`SKILL.md` 5단계) → 조립(6단계)

## 롱폼 조립 요약

```bash
ffmpeg -f concat -safe 0 -i listA.txt -c copy masterA.mp4
ffmpeg -f concat -safe 0 -i cycle.txt -c copy cycle.mp4      # A,B 이어붙임
ffmpeg -i cycle.mp4 -af "loudnorm=I=-16:TP=-2:LRA=5" -c:v copy cycle_norm.mp4
ffmpeg -stream_loop -1 -i cycle_norm.mp4 -t 3600 -c copy 1hour.mp4
```

클립마다 앞뒤 40ms 페이드를 넣지 않으면 이음새에서 틱 소리가 난다. 수면용에서는 이것만으로 실패한다.
