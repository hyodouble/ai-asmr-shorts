# ai-asmr-shorts

AI ASMR 영상을 기획→프롬프트→렌더 검수→후처리→업로드까지 자동화하는 Claude 스킬.
쇼핑/쿠팡 연동 없음, 상품 구매 없음, 얼굴/목소리 노출 없음.

배포물은 두 종류다.

- **숏폼 30초** (10초 클립 3개, 매일 1편) — 지금 주력. 니치는 **글래스 커팅 ASMR**(유리 과일 자르기)
- **수면용 1시간 롱폼** (10초 클립 20개 → 마스터 2종 교차 → 1시간) — 니치는 **스퀴시 ASMR**

**규칙 전문은 [`SKILL.md`](SKILL.md) 하나에 있다.** 숏폼과 롱폼은 규칙이 다르니 섞지 말 것
(숏폼은 유리의 쨍한 소리가 상품이라 `detone.py`도 `lowpass`도 쓰지 않는다).

## 구성

| 파일 | 용도 |
|---|---|
| `SKILL.md` | 워크플로우 전문. 프롬프트 블록, 검수 기준, 후처리 체인, 배포 규칙, 발행 이력 |
| `scripts/mix-foley.sh` | 1단계. AI 오디오 위에 CC0 foley를 -16 dB로 레이어링 (`raw/` → `rawfx/`) |
| `scripts/build-short2.sh` | 2단계. 프리게인 + 2패스 loudnorm으로 -14.5 LUFS / TP -1.0 (`rawfx/` → `out2/`, 30초 마스터까지) |
| `scripts/make_overlays.py` | 3단계. 후크·씬 넘버링 오버레이 PNG 3장 (ffmpeg에 drawtext가 없는 환경용) |
| `scripts/finish-short.sh` | 4단계. 씬별 오버레이 합성 + 1.7배속 17.6초 → `out/short_final.mp4` |
| `scripts/build-short.sh` | 구 1패스 파이프라인. 조용한 원본에서 -14.5 LUFS에 못 닿아 지금은 안 쓴다 |
| `templates/short-glass-cutting.txt` | 글래스 커팅 3막 프롬프트 전문(유리 키위 기준) |
| `tonecheck.py` | FFT 톤 검사. 모델이 몰래 넣는 벨/차임 탐지 |
| `detone.py` | 톤 성분 제거(롱폼 전용). 적용 전후로 tonecheck 재확인 필수 |
| `niche.md` | 니치 포인터 |

## 이 프로젝트에서 실측으로 알아낸 것

- **모델은 프롬프트 금지어를 무시하고 벨/차임을 넣는다.** `no chimes, no bells`를 넣어도 3회 연속 들어갔다.
  프롬프트를 고쳐 재생성하지 말고(크레딧만 나간다) `detone.py`로 지운다. 단 만능이 아니라 악화되는 클립도 있다
- **소음은 증폭 전에 자른다.** 원본이 -37~-48 LUFS라 20 dB 넘게 올려야 하는데, 신호는 1~10 kHz에만 있고
  20~200 Hz는 럼블, 10 kHz 위는 히스다. 대역 필터 + `afftdn`으로 SNR 29 → 39 dB
- **`alimiter`는 기본값이 `level=true`라 리밋 후 출력을 도로 올린다.** `limit=0.5`를 걸고도 피크가 +0.6 dBFS로 클리핑났다. `level=disabled` 필수
- **AAC 인코딩이 피크를 약 5 dB 밀어올린다.** 유리 파열음 같은 조밀한 트랜지언트에서 -6.9 → -1.7 dBFS. 숏폼 리미터 천장을 0.45로 잡는 이유
- **라우드니스 목표는 롱폼 -20~-24 LUFS.** 원본이 작아 -16까지 밀면 리미터가 계속 물려 뭉갠다
- **가로 소스를 그대로 올리면 Shorts로 분류되지 않는다.** 9:16 재렌더링 후 업로드하고 `youtube.com/shorts/...` 링크로 확인
- **1.2K 조회수 천장은 완주율(APV)과 스와이프율(VVSA) 부족 때문 (2026-09-19 발견).** 30초 고정은 숏폼 피드에서 너무 길어 15~18초 압축 또는 무한 루프가 필수다. 화면 상단 텍스트 후크(Which would you choose?)와 첫 댓글 고정이 인게이지먼트를 뚫어준다


## 사용법

1. 클로드에서 `/ai-asmr-shorts` 실행
2. 씬 목록과 **프롬프트 전문을 승인받은 뒤** Flow에 입력 (크레딧이 곧 돈이다)
3. 숏폼: 클립 3개 → `sh scripts/build-short.sh <작업폴더>` → 업로드 → 자막 5개 언어 게시
4. 롱폼: 후처리(5단계) → 1시간 조립(6단계)
